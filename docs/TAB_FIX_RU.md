# Обновление табулатуры

1. Запустите новый GuitarTabAI.exe.
2. В поле «Аудио» выберите «Автоматически (Basic Pitch)».
3. Выберите «Гитара: аккорды и арпеджио» для аккордов либо «Мелодия: одна нота
   за раз» для одноголосного риффа/соло.
4. Нажмите «Анализировать видео», чтобы заменить старый автоматический результат.
   Ручные исправления сохраняются. Открытие старого проекта само по себе не
   пересчитывает ноты.
5. Если остаётся много слабых срабатываний, поднимите «Порог нот» с 0.45 до 0.60
   и повторите анализ. При этом тихие настоящие ноты также могут пропасть.

На TAB показаны номера ладов на струнах. Жёлтый номер означает сомнительную
ноту или аппликатуру; подробности доступны при наведении. Точки при малом
масштабе обозначают плотные атаки: увеличьте «Масштаб», чтобы увидеть номера.

Вокал, бас, клавиши и ударные в общей записи могут давать чужие ноты. Модель
распознаёт высоты звуков, но не отделяет гитару от остальных инструментов.
Лучший исходник — отдельная дорожка гитары. Без исходного видео нельзя
подтвердить правильность конкретной распознанной партии.
